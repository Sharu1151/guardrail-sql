## 🚀 Key Features in this Version

1. **Voice Query Microphone**: Hands-free natural language querying using the Web Speech API.
2. **AI Direct Answer & Insights**: Automatic executive synthesis answering business questions in plain English.
3. **Multi-Tier Security Firewall**:
   - SQLGlot Abstract Syntax Tree (AST) compiler firewall blocking destructive DDL/DML.
   - Dynamic SHA-256 PII masking for emails, phone numbers, and sensitive fields.
   - Cost governor execution limits.
4. **Touch-Optimized Charts**: Interactive SVG Bar charts, Donut charts, and Line trend charts formatted for mobile devices.
5. **Schema Explorer**: Relational tables browser with column definitions and row counts.
6. **Configurable Endpoint**: In-app backend selector supporting Localhost, LAN Wi-Fi IP, or Cloudflare public tunnels.
